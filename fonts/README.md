# Bundled label fonts

These files are used by the current SleetPOS label renderer. They were copied
without modification from `../POSSystem2/sleet-dashboard/public/fonts/` by
`tools/build-label-engine.mjs`. Website typography uses Manrope through Google
Fonts; these Roboto files preserve the printed label renderer's typography.

The versions, copyright notices, and license identities above are retained in
the original font files' `name` tables. The full licenses are included alongside
the fonts:

- `LICENSE-Roboto.txt`: official Apache License 2.0 text from
  <https://www.apache.org/licenses/LICENSE-2.0.txt>.
- `OFL-RobotoMono.txt`: project copyright notice and OFL 1.1 from
  <https://raw.githubusercontent.com/googlefonts/RobotoMono/main/OFL.txt>.

License texts were retrieved on October 6, 2026. Trailing whitespace was
normalized without changing the license wording. The Roboto Mono project notice
matches the bundled font metadata. These copies document the licenses of the
bundled versions; no font files were upgraded or regenerated.
